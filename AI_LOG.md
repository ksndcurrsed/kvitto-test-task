# AI log

## Инструменты и модели

Использовался Codex на базе GPT-5.6 Luna для чтения PDF-ТЗ, проектирования API, реализации кода и проверки тестами. Для извлечения текста из PDF использовался bundled Python runtime и `pypdf`.

## Ключевые запросы

1. «Прочитай ТЗ в PDF и реализуй всё, кроме GitHub Actions, Alembic и правил ассистента; стек - FastAPI, Python, PostgreSQL, Docker Compose». Контекстом был PDF из корня репозитория.
2. «Сделаем» после предложенной архитектуры. Контекстом были согласованные endpoints, денежные правила, idempotency, статусы и бонусные HMAC/фильтры.
3. «Реализуй по плану Native». Контекстом были письменные design spec и implementation plan.

## Проверка и найденная ошибка

В процессе проверки отдельно проверялась integer-арифметика для скидки и рассрочки. Первоначально в модели не был указан явный внешний ключ `payments.tariff_id -> tariffs.id`; это было замечено до интеграционного прогона и исправлено. Также Docker CLI оказался доступен, но Docker daemon в среде не запущен, поэтому PostgreSQL smoke test требует запуска daemon локально.
